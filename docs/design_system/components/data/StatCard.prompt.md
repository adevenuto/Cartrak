One-line: A compact metric tile — icon, label, and a bold value — for health/efficiency readouts.

```jsx
<StatCard icon={<EngineIcon/>} label="Engine Health" value="92%" />
<StatCard tone="glass" label="Tire Condition" value="85%" />
```

`tone="glass"` for translucent tiles floating over a photo/gradient hero; `card` (default) on the gray canvas.
