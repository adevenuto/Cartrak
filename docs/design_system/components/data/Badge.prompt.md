One-line: A small pill label for specs, counts, durations, and status.

```jsx
<Badge tone="neutral">Automatic</Badge>
<Badge tone="brand">+32</Badge>
<Badge tone="brand-soft" leftIcon={<ClockIcon/>}>45 min</Badge>
```

Tones: `neutral` (gray), `brand` (red fill), `brand-soft` (pale red), `dark`, `outline`. Always fully pill-rounded.
