One-line: A round icon control for headers and toolbars (bell, calendar, heart, back).

```jsx
<IconButton tone="light"><BellIcon/></IconButton>
<IconButton tone="brand"><BellIcon/></IconButton>
```

Tones: `light` (white chip + soft shadow, the default header style), `brand` (red fill), `ghost` (transparent), `dark`. Default diameter 44px — the minimum touch target. Pass an icon as children.
